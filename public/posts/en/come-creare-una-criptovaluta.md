## Ways to "create" Crypto

I showed you how in reality most **Crypto products** are not created from scratch, but only built on a pre-existing structure.

So, recapping, what are the ways to **create a Cryptocurrency**?

- Build a **Token** on an existing Blockchain
- Modify an existing Blockchain (**Fork**) or create a new one
- Create a Blockchain starting from an already built **core**

The first method is very simple. If you want to create a Token without any additional **functionality**, it takes a few minutes.

Clearly, you cannot expect to achieve who knows what result.

If you are interested in this fast option and moreover **without code**, I wrote an article explaining how to do it in a few simple steps: [How to create a crypto in 10 minutes: Complete Tutorial](https://www.matteoraggiblog.com/come-creare-una-crypto/).

Otherwise, even more complex **Tokens** can be created, and not simply capable of being transferred between two [wallets](https://www.matteoraggiblog.com/migliori-wallet-crypto/).

The second method I advise against. It has been historically used mainly to propose important changes to networks like **Bitcoin**.

But they have always been initiatives that have met with little success. This is because **Bitcoin** is a completely functioning and efficient network, and a substantial change can bring **more risks than benefits**.

Instead, creating it without even starting from a small pre-built structure would require too much time and also an entire **team** behind it.

To obtain a result maybe not even superior to what can be obtained with technique number three.

The third method is what I recommend if your interest is creating a **new Blockchain**.

So start from an already **programmed** base, taking it from **open-source** projects like Ethereum.

The Cryptocurrency that will be associated with this network will be a **proprietary Crypto**, not a Token. The fact of starting from already written code changes nothing from this point of view.

So let's see how to create a Blockchain with this method.

## Building a Blockchain

The first thing you need to know is that it is a long job, very long. It is not something feasible in a few days.

It requires research, study, and many hours spent on **code**. Especially if you have little confidence with **programming**.

The fundamental requirements that a Blockchain must have are:

- A network
- Cryptography
- A data structure and management algorithms
- A decentralized system

To create a Blockchain this way, you must first decide which **network** to take inspiration from to start.

On Github you can find all **open-source Blockchain** projects. You can freely take and use all the code you want. These are the Blockchain projects present on Github: [Blockchain Projects](https://github.com/topics/blockchain).

Once the code is chosen you will have to understand it and figure out where to put your hands to change it. Remember to always respect the **key concepts** of every Blockchain network.

## 5 Key Concepts of the Blockchain Ecosystem

- Cryptography **through** Hash coding and digital signature to verify identity
- **Irreversible** transactions
- **P2P** Network (unlike the Client-Server system where the structure is hierarchical, here all nodes have the same importance)
- Choice of **consensus** algorithm (PoW or PoS)
- **Block** validation method (Mining, Forging,..)
