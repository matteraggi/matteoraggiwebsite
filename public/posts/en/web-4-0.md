## Web 4.0?

I have heard about **Web 4.0** several times as if it were a further evolution after **Web 3.0**. Its main characteristics are always the same: Artificial Intelligence, Semantic Web, [Metaverse](https://www.matteoraggiblog.com/metaverso/), and Blockchain.

All these novelties just listed, however, belong to Web 3.0, not Web 4.0.

**The truth is that Web 4.0 does not exist**

At least for the moment.

Many make the mistake of calling what is actually Web 3.0 by this name, but let's clarify.

## The Web in short

We are not talking about different **Webs**.

The Web is one: 1.0, 2.0, 3.0, and 4.0 are "updates" or rather **evolutions** of it.

And they are not sudden updates, as is done for applications or programs, but are slow evolutions.

These evolutions represent the **technological advancement** of our society.

Over the years, **technology** makes great strides, and so slowly the Web transforms and updates continually.



[**Web 1.0**](https://www.matteoraggiblog.com/web-1-0/) was the original Web, static and for the few.

Then came [**Web 2.0**](https://www.matteoraggiblog.com/web-2-0/): it was called so when Blogs and **Social Networks** like Facebook were born.

Finally, [**Web 3.0**](https://www.matteoraggiblog.com/web-3-0/) is what has been developing for several years.

With new technologies such as: **Blockchain**, Machine Learning, [Artificial Intelligence](https://www.matteoraggiblog.com/intelligenza-artificiale-nella-vita-quotidiana/), and Semantic Web.

## Web 3.0 = Web 4.0

So when you hear about **Web 4.0**, it is very likely that they are talking about 3.0.

The use of this notation is only for **sensationalist purposes** and is used to deceive the reader that we are talking about a futuristic evolution.

In reality, **they are exactly the same thing**.

## So does it exist?

If it is considered more of a **future idea** than a current development, then it can be called this way.

But they are mostly speculations on what the next **technological innovations** could be.

If, however, the characteristics attributed to Web 4.0 are those I talk about [in this article on Web 3.0](https://www.matteoraggiblog.com/web-3-0/), there is a mistake.

## Web 3.0

**Web 3.0 is what you were looking for**. This is the name given to the slow evolution that is leading [**Internet**](https://www.matteoraggiblog.com/motore-di-ricerca-cos-e/) to be something more than what we are used to with Websites and Social Networks.

It is a slow process that is bringing the Internet and people even closer, making it more **decentralized**.

All these evolutions that have been going on for years aim to be able to dedicate a **private space on the Web** to each person.

There are many improvements and many technological advancements that will then lead to complete achievement.

To cite some of the technological inventions of recent years: **Artificial Intelligence** and **Blockchain**.

Artificial Intelligence serves to bring **man and machine** closer and to make our computers more capable of **understanding human language**.

Blockchain will increase **digital security** for every single user, and being decentralized, it will help create a place at the service of everyone.
